# Onboarding for new CampusKart contributors (synthetic demo data)

1. Clone the repo and copy `.env.example` to `.env`.
2. Run the web app and the API locally; both have a README section.
3. Pick a "good first issue" and ask in #dev before starting.
4. Windows users: use WSL if the build complains about paths.
5. Ask in #general if you are unsure who owns something.

Tone: friendly, short messages, Hinglish is fine in chat.
